# research

What GateKit has found out about the game, kept as data and studies, and the one ledger of what is
decided and open. It is not documentation: that is [docs/](../docs), and where the two disagree
the documentation wins. Nothing of Larian's is committed here either (no game data, binaries,
decompiled code, fonts or textures; [CONTRIBUTING.md](../CONTRIBUTING.md)).

| | |
|---|---|
| [`open-items.md`](open-items.md) | the ledger: what is decided and what is still to do, one item each |
| [`coverage/`](coverage) | the coverage record: component layouts, system descriptions, sightings, replays, wishes, leads and counts, each written by a `gatekit` command or tool ([its README](coverage/README.md)) |
| [`studies/`](studies) | studies of one question each: why a mod stalls, how a program could drive Larian's editor |
| [`se-fork/`](se-fork) | about GateKit's Script Extender fork, which lives in its own repository: offers to upstream and a proposal for a native element engine |

What a study must show, and how a mechanic is studied: [docs/writing-tests.md](../docs/writing-tests.md),
"The method".
