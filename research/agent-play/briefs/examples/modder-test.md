## Test task (an example for modders)

Instead of playing through, test one thing and report on it.

1. Find every container you can reach in the first area and open it (`do loot`, `contents`).
2. For each one, note its name, whether it was locked or trapped, and what was inside.
3. If a container shows something unexpected (an item with no name, an empty name, an error),
   save the game right there with `save` and a label that says what is wrong.
4. Finish with a table: container, place, locked/trapped, contents, anything odd.

Do not fight unless attacked; do not leave the first area.
