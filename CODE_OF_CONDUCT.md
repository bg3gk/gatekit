# Code of conduct

This is a small project. The rules are short because they can be.

## What is expected

Be civil. Disagree about the work, not about the person. Assume the other side is trying to
help until they show otherwise.

## What is not tolerated

Harassment, insults, and abuse directed at anyone — in issues, pull requests, commit messages or
anywhere else this project reaches. Sexual attention nobody asked for. Posting someone's private
information. Persistently derailing a discussion after being asked to stop.

## Reporting

Open an issue, or write to the owner, [@Gwynerva](https://github.com/Gwynerva), through GitHub.
Reports are read by the owner alone. If a report is about the owner, GitHub's own
[reporting](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
goes over their head, and nobody here will hold it against you.

## What happens then

The owner decides, and says what was decided: usually a word in private, sometimes an edit or a
deletion, and in a bad case a block. There is no committee and no appeal beyond GitHub's own.

**A disclaimer, so nobody is misled**: this project is run by one person with the help of AI
agents. Enforcement means what one person can do in their own repositories, when they next read
their notifications. It is not a moderation team and should not be relied on as one. If you are
in danger, a code of conduct is the wrong tool — contact GitHub or, where it applies, the
authorities.

This is not the Contributor Covenant, deliberately: a shorter text that is actually read is
worth more than a longer one that is not. Nothing here grants fewer protections than that
document intends.
