<h3 align="center">Map · Extend · Automate</h3>

Tools for developing **Baldur's Gate 3** mods without babysitting the game: it starts by itself
into a test level, a mod's Lua reloads while it runs, and everything inside it can be read and
driven from code — by a person, a test, or an AI agent.

| | |
|---|---|
| [**gatekit**](https://github.com/bg3gk/gatekit) | the toolkit: the stand, the in-game bridge, the MCP server, the offline tools |
| [**bg3se**](https://github.com/bg3gk/bg3se) | our fork of [Norbyte's Script Extender](https://github.com/Norbyte/bg3se), which everything here stands on |
| [**map**](https://github.com/bg3gk/map) | prebuilt maps of the game: its own content, the engine's symbols, our component map |

Mods published here are named `mod-*`.

**Experimental.** Everything is in active development and none of it is production-ready.
Commands, APIs and file formats change without notice.

**How it is built.** Mostly by AI coding agents working under the continuous direction and
review of [@Gwynerva](https://github.com/Gwynerva), who decides what is built and approves every
change. Published text is signed so you always know what you are reading.

Unofficial fan projects, not affiliated with Larian Studios.
